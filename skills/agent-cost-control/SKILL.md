# Agent 成本节约

持续推进有效工作；等待本身不应反复唤醒模型。本规范约束主代理及其整棵子代理树。
遵循上层约束和用户最新指示，保留已有授权、必要验证与交付质量，不因节约成本擅自停任务。
普通短问答不增加规划、监控台账或审批流程。

## 子代理：禁止 Astra，缩小派单

- 只在用户或适用规范允许委派时创建子代理；本 skill 不自动授予委派权限。
- 下发子代理不得使用 Astra，也不得继承主代理 Astra、通过角色配置覆盖或另启 CLI 绕过。
  显式选择可用非 Astra 模型；默认 `gpt-6.1-sol`、`low`，任务需要时可用非 Astra 的适当推理档。
  派单前检查模型选择与角色覆盖，启动回执可见时再次核实。不能可靠选择/核实则不创建，说明限制。
  此规则不要求更改主代理模型；后续用户明确改变模型要求时记录该例外的范围。
- 派单前确定一个独立交付物、必要输入、验收问题、允许改动、停止条件与返回时机。
  只传必要文件和状态摘要，不默认复制整段历史。支持独立上下文时使用它；当前工具中
  `fork_turns="all"` 会继承模型且不接受模型覆盖时，使用 `fork_turns="none"` 并补齐必要任务上下文。
- 不为普通状态检查创建模型代理；子代理不自行再派代理、扩大实验矩阵或持续修复超出任务的问题。
  只在完成、阻塞、关键反例或需要决策时返回；不频繁催报或相互重复监督。
- 完成后验收已有证据并结束该子任务；复用有效结果，不无理由重新读取整个工程或重复全部验证。

## 等待：一个监控者，无变化不唤醒模型

- 每个后台作业指定唯一监控者，优先使用不调用 LLM 的执行器/检查程序。
  主代理和子代理不得同时监督同一作业。沿用任务现有状态位置记录：作业标识、监控者、
  结果位置、成功/失败判据、截止时间、下次检查时间。无需每次重读完整日志。
- 同一状态查询连续两次无实质变化，退出模型轮询。时间戳变化不算进展；换等价命令、
  更换代理或频繁列出代理状态也不能重置计数。改为执行器等待、退避检查或可靠检查点接续。
- 进入等待前简要说明已完成什么、还等什么、预计时间、建议检查间隔和恢复条件。
  用户已授权的等待直接采用低成本方式，不为同一偏好反复确认。
- 定时检查在执行层完成：未满足要求但正常运行就继续等待，不把每次检查送给模型。
  满足验收、失败、超时或确需决策才返回主代理。检查间隔应与预期运行时间相称，
  采用退避和有限截止时间；不要创建无限循环或高频新模型会话。
- 进程退出、文件出现不等于合格；使用事先约定的机器可检查判据。只有必要的语义验收
  才调用一个非 Astra 子代理或主代理，不能每次定时检查都重新做完整分析。
- 定时器必须有真实设置回执，包含触发时间、检查入口、结果位置及回主代理通道。
  只写脚本、待办或执行 sleep，不能证明退出当前轮次后能唤醒对话。没有可靠恢复能力时
  如实说明，遵守当前工具/会话的跟踪与等待要求；若需改成用户稍后接续，再一次性询问。
  不用应用周期自动化绕过单项作业跟踪限制，不宣称并不存在的后台监控。
- 到检查点只读新增/变化状态；无新信息不重新塞入完整日志或长历史。主代理仍有独立有效工作时
  可继续工作，但不得借此重复查询已委派的后台作业。

## 审查：独立证据，不重复劳动

- 实施者、独立测试和审查各自有不同验收目标与证据边界。真正需要独立复现时保留独立性，
  不让多个代理都读完整工程、做同一种泛化检查。审查子代理同样禁止 Astra。
- 有效检查已通过、没有新改动/失败或尚待解决的问题时，不重复运行同一检查。
  新证据需要重测时说明理由，不借成本规范跳过必要验证。
- 长任务按阶段交接，保存简短已验证状态和下一步。对反复失败预设停止/升级条件；
  无新证据不自动扩大任务、追加实验或连续重开代理。

## 安装、启用与可验证边界

安装本目录后通过 `$agent-cost-control` 调用。自动匹配不等于每个对话都会加载；如需个人默认，
在现有全局 `AGENTS.md` 或个人协作规范中加入“长任务、等待或委派前读取已安装的
`agent-cost-control/SKILL.md`”的入口，实际路径以本机为准。修改入口、配置或安装服务仍需相应授权。

Codex 支持时，可在用户授权后为 `config.toml` 设置以下兜底值（本 skill 不自动写配置）：

```toml
[agents]
default_subagent_model = "gpt-6.1-sol"
default_subagent_reasoning_effort = "low"
```

默认值可能被显式派单或角色配置覆盖，不能称为 Astra 硬封禁。技能文本也不是运行时拦截器；
区分安装、加载、理解、真实行为验收，不声称旧对话/远程主机已自动刷新。

核对或验证时读取 [行为验收](references/verification.md)。默认先做不执行真实任务的场景检查；
真实子代理或计时器实测须有授权，不为验证本 skill 启动昂贵任务。

成本复盘统计主代理和子代理树，分开模型、未缓存输入、缓存输入、输出及响应次数。
累计 token 不是官方额度扣减公式；不要把其他账户/工作区的额度快照混在一起归因。
